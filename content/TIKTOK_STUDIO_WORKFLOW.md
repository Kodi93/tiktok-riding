# TikTok Studio workflow

## Working production path

1. Build three or more vertical stills from owned/licensed assets or original graphics.
2. Use the local transition render to create the 6–8 second master: hook in the first second, escalation by roughly three seconds, payoff by five to six seconds, immediate cut.
3. Encode the upload master as constant 30 fps H.264/yuv420p with AAC audio and fast-start MP4.
4. When TikTok Studio accepts the upload, use its native finishing controls for sound, text, cover selection, caption, and schedule.
5. If Studio's local media parser rejects the upload, keep the finished master and use the connected approved scheduler. Do not repeatedly retry a failing upload.
