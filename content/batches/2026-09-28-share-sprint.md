# 2026-09-28 Shareability Sprint

## Goal

Move Zeph Rides from paid-follow proof of concept toward an organic repeat-view/share loop.

The sprint is deliberately built around premises riders immediately recognize, fast visual payoffs, recurring Zeph visual identity, and send-to-a-friend behavior. Generic scenic POV does not qualify unless the footage contains a specific story, reveal, encounter, or exceptional riding moment.

## Baseline entering sprint

- 12.1K overall post views / 28-day snapshot
- 506 likes
- 23 comments
- 4 shares
- 89 profile views
- $43 Promote spend
- 2.44K Promote views
- 157 Promote-attributed followers
- paid follower acquisition ~= $0.274/follower
- promoted view-to-follow ~= 6.43%
- overall share/view ~= 0.03%
- overall profile-view/view ~= 0.74%

The weak visible signal is sharing. The next batch therefore treats "would one rider send this to another?" as a release gate.

## Batch rules

1. Hook must land on frame 0 or within the first 0.5s.
2. Punchline or reveal should arrive by 5-8s for short comedy unless the tension genuinely earns a longer runtime.
3. No home, driveway, or garage imagery.
4. Visor-down / helmet-on identity is preferred when a rider appears.
5. No unsafe riding demonstrations, speed challenges, road rage, or imitation-worthy dangerous behavior.
6. Reuse structure, not exact jokes. Each concept needs a distinct setup/payoff.
7. Use the Zeph lime/black visual language as an accent, not as a full-screen template on every post.
8. At least four cover families across every nine posts.
9. Promote only after the creative earns it or when running a tightly bounded acquisition test.
10. Capture metrics at 2h, 24h, 72h when available.

## Measurement plan

For each post, record when available:
- organic vs promoted views
- average watch time
- completion
- rewatches
- likes
- comments
- shares
- saves
- profile visits
- follows

Primary sprint success signals:
- repeated posts above the account's recent organic median;
- share rate materially higher than ~0.03%;
- profile-view conversion above ~0.74%;
- at least one concept that can be repeated without feeling like a clone;
- promoted followers demonstrably participating in later organic posts.

## Kill / iterate rules

- If a concept underperforms but has strong completion and shares, revise the hook rather than killing the format.
- If it gets views but almost no shares/profile activity, treat it as entertainment without channel-building value.
- If a format fails 4-6 materially different executions, demote it.
- If a format produces multiple organic outliers, immediately create 3 adjacent concepts while the audience association is fresh.
