# Zeph Rides — Visual Language & Art Direction

## Purpose

This document defines how Zeph Rides should look across TikTok posts, thumbnails, stills, graphics, and future cross-platform assets.

The goal is not uniformity. The goal is recognizable authorship with enough variation that the profile never becomes visually monotonous.

## Core aesthetic

- Appalachian roads and atmosphere
- dark rider/bike silhouette against natural environment
- natural greens, gray pavement, yellow centerlines, metallic bike details
- cinematic framing without over-processing
- slightly moody / grounded rather than glossy influencer perfection
- authentic motorcycle details over fake spectacle

## Visual contrast strategy

Adjacent posts should deliberately contrast at least two of these dimensions:

- wide vs close
- rider present vs rider absent
- bright vs dark
- road vs machine detail
- moving vs stationary
- text-heavy vs text-light
- human/animal encounter vs scenic
- cockpit POV vs third-person bike visual
- daytime vs dusk/night
- dense background vs clean composition

## Cover families

### A. Rider Hero
Full or partial rider with motorcycle. Use strong silhouette, low-angle or three-quarter composition, helmet on.

### B. Bike Hero
Motorcycle dominates frame. Favor clean lines, reflections, lighting, recognizable details.

### C. Curve / Road Reveal
Road geometry is the subject. Avoid generic straight pavement or repetitive guardrail compositions.

### D. Encounter
Animal, rider, pedestrian reaction, unusual roadside moment, or another real event. The encounter should be genuinely present in the post.

### E. Detail
Controls, cluster, glove, mirror, tire, fairing, startup, hybrid detail, fuel stop, key/ignition, light, etc.

### F. Destination / Environment
Scenic pull-off, overlook, bridge, town, forest, weather, tunnel, unusual road feature.

### G. Humor / Graphic
Text or simple graphic is the main visual idea. Keep it clean and native-feeling.

### H. Night / Mood
Instrument lighting, headlight, silhouette, reflections, low-light environment.

## Thumbnail composition rules

- One clear focal point.
- Avoid tiny subject matter lost in a wide frame.
- Avoid critical text in UI-covered zones.
- Text should usually be 2–7 words, not a paragraph.
- If text is used, it must add curiosity or orientation; it should not simply restate the caption.
- Use crop and scale aggressively enough that the grid thumbnail still reads on a phone.
- Do not use more than two adjacent thumbnails from the same cover family.
- In any nine-post window, target at least four cover families.

## Source rules

Preferred:
1. real frame from the post;
2. original still from the same ride;
3. original bike/rider image;
4. purpose-built relevant graphic;
5. generated visual that accurately represents the concept;
6. licensed/sourced visual with documented rights.

Avoid using a sourced image merely because the actual footage has a weak frame. If a sourced cover would misrepresent what the video contains, redesign the post or insert a truthful cover frame into the video itself.

## In-video cover-frame tactic

When TikTok does not support an independent cover for the publishing path:
- add a clean 0.3–0.7 second visual at the beginning or end that is genuinely connected to the post;
- ensure it can be selected as the cover;
- avoid damaging first-second retention if placed at the beginning;
- prefer the end if the opening hook is stronger without it.

## Generated-image standard

Generated assets must pass a realism check:
- correct motorcycle geometry;
- plausible wheels, bars, mirrors, controls, lights, and rider anatomy;
- no warped road markings;
- no invented logos or garbled text;
- no impossible reflections or duplicate body parts;
- no fake event presented as documentary footage.

Generated imagery should function as art direction, not deception.

## Text system

Keep typography consistent enough to feel authored, but vary layout by concept.

Recommended modes:
- minimal centered hook;
- upper-third hook;
- small subtitle-like statement;
- bold 2–4 word graphic for humor/reaction;
- no text when visual alone is stronger.

Never let every cover use the same white text in the same position.

## Feed review

Before scheduling a batch, create a rough 3x3 mental or physical grid and ask:
- Can I distinguish each post instantly?
- Does one visual mode dominate?
- Are there enough rider/bike/detail/encounter images to break up pavement?
- Does it look like a creator brand or a dashcam archive?
- Is there at least one image that makes someone stop and inspect the profile?

If the answer is weak, the batch is not ready.
